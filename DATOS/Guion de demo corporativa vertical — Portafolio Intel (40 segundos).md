# Guion de demo corporativa vertical — Portafolio Intel (40 segundos)

> **Duración objetivo:** 40 segundos.  
> **Formato:** 9:16 vertical, 1080 × 1920, cuatro clips de diez segundos.  
> **Audiencia:** responsables financieros y equipos corporativos.  
> **Mensaje:** menos consolidación manual, mayor control operativo y decisiones más claras; sin prometer ahorros cuantificados ni asesoramiento financiero.

## Locución final

«Cuando los datos de cartera viven en plataformas, hojas y correos distintos, cada consolidación consume tiempo y multiplica el trabajo manual. Portafolio Intel reúne posiciones, evolución y alertas en una única vista segura, para revisar lo relevante con menos búsquedas.

Configure las fuentes autorizadas, previsualice antes de escribir y detecte errores antes del retrabajo. Las alertas priorizan excepciones y el panel refleja cambios autorizados sin recargar.

Portafolio Intel: eficiencia, trazabilidad y control para decidir con claridad.»

## Salvaguardas de comunicación

La pieza debe usar datos sintéticos o abstractos. No debe mostrar nombres de clientes, datos de cartera reales, correos, claves, importes, rentabilidades garantizadas ni botones de compra/venta. La integración real de Google Sheets sigue requiriendo OAuth de servidor y validaciones; el vídeo no debe presentarla como ya habilitada para importación productiva.
