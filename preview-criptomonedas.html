Simulación didáctica · cadena FIFO

Una cadena de permutas transmite el coste de un activo al siguiente

Caso ficticio para comprobar la trazabilidad del coste. Cada permuta calcula un resultado y crea un lote para la siguiente operación.

3 transmisiones
Paso 1 · Permuta

0,20 BTC → 3 ETH

Coste FIFO BTC: 6.000 €. Valor de referencia documentado: 7.500 €. Se crea un lote ETH con coste de 7.500 €.

7.500 € − 6.000 €+ 1.500 €
Paso 2 · Permuta

2 ETH → 50 SOL

Se consume 2/3 del lote ETH: coste FIFO 5.000 €. Valor de referencia: 5.400 €. Se crea un lote SOL con coste de 5.400 €.

5.400 € − 5.000 €+ 400 €
Paso 3 · Venta

50 SOL → EUR

Valor bruto: 5.900 €; comisión: 20 €; transmisión neta: 5.880 €. El coste FIFO del lote SOL es 5.400 €.

5.880 € − 5.400 €+ 480 €
◇Resultado acumulado ilustrativo: + 2.380 €. Queda 1 ETH con coste FIFO de 2.500 €. Si falta valor EUR, activo recibido, cantidad o inventario, el motor bloquea la cadena desde esa operación.
