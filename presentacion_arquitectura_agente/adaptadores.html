Adaptadores de Servidor

Aislamiento de secretos

Las API keys de proveedores comerciales (FMP, CoinGecko) residen exclusivamente en el entorno del servidor, nunca se exponen al navegador del usuario.

Control de límites (Rate Limiting)

El adaptador gestiona y respeta estrictamente las cuotas de acceso, como el límite de 10 peticiones por segundo exigido por las políticas de la SEC.

Caché y normalización

Las peticiones repetidas leen directamente desde el snapshot almacenado. Esto reduce drásticamente la latencia, minimiza el coste de API y estandariza el formato de los datos.
