El problema: Datos vs. Privacidad

Riesgos del enfoque tradicional

  • Exposición de secretos

    Un LLM conectado directamente puede exponer claves al cliente.

  • Fuga de datos

    Riesgo de mezclar contextos entre organizaciones.

  • Inyecciones de prompt

    Documentos externos podrían introducir instrucciones maliciosas.

Arquitectura en 3 capas

  • 1. Cliente autenticado

    Envía intención y contexto sin exponer secretos.

  • 2. Edge Function Guardián

    Valida permisos y limita accesos a solo lectura.

  • 3. Modelo IA Aislado

    Recibe contexto mínimo y devuelve respuestas estructuradas.

No queremos que el cliente consulte la BD completa ni que la API key llegue al navegador.
